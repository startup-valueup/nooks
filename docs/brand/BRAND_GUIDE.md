# NOOKS 브랜드 가이드

1단계에서 정한 브랜드 기준입니다. 카피는 초안이므로 운영자가 확정하기 전까지는 사실 주장(설립 연도, 제작 방식, 소재, 원산지 등)을 넣지 않았습니다.

## 이름

**NOOKS** — 영어 _nook_, 아늑하게 머물 수 있는 작은 구석에서 가져왔습니다. 크지 않아도 마음이 놓이는 자리, 그런 자리를 위한 물건을 다루는 브랜드입니다. 특정 상품군을 정해 두지 않으므로 이름과 메시지는 어떤 생활용품에도 어울리도록 "자리"를 중심에 둡니다.

- 로고타입은 항상 대문자 `NOOKS`, 자간 0.2em, Bold(700).
- 문장 속에서는 `NOOKS` 그대로 쓰고 조사는 붙여 씁니다. (예: NOOKS는, NOOKS가)

## 메시지

| 구분                   | 문구                                          |
| ---------------------- | --------------------------------------------- |
| 태그라인               | 머무는 자리를 위한 물건                       |
| 히어로 헤드라인        | 일상의 작은 자리를, 가장 좋은 자리로          |
| 브랜드 선언            | 물건은 자리를 만들고, 자리는 하루를 만듭니다. |
| 브랜드 이야기 헤드라인 | 작은 자리에도 품격이 머뭅니다                 |

선별 기준(메인페이지 · 소개 페이지의 핵심 원칙): **오래 곁에 둘 수 있는가 · 차분하게 어울리는가 · 쓰임이 분명한가.** 키워드는 오래(Lasting) · 차분(Calm) · 쓰임(Useful) · 단정(Refined).

### 어조

- 차분하고 정중한 합쇼체(~합니다). 과장·최상급·느낌표를 쓰지 않습니다.
- 모르는 것은 말하지 않습니다. 확정되지 않은 일정·가격·사양은 "준비 중"으로 표시하고 숫자를 지어내지 않습니다.
- 한 문장에 한 가지 이야기. 명사형 종결보다 서술형을 우선합니다.

## 로고 마크

벽에 낸 오목한 자리(니치)를 닮은 **아치**입니다. 아치 안쪽을 비워 '아직 아무것도 놓이지 않은 자리'를 표현했고, 모양은 알파벳 n으로도 읽힙니다.

- 소스: [`nooks-mark.svg`](./nooks-mark.svg) (컬러), 컴포넌트 `src/components/BrandMark.astro` (`currentColor`).
- 기본 색은 모스 그린(`#3b5645`), 어두운 배경에서는 `#a9c4b1`. 본문 안에서는 잉크색(`#1a1816`)도 허용합니다.
- 마크 높이의 절반 이상을 여백으로 둡니다. 늘리거나 기울이거나 효과를 주지 않습니다.
- 헤더 락업은 마크 22px + 로고타입 17px, 간격 10px.
- 파비콘은 같은 마크이며 다크 모드에서 밝은 색으로 바뀝니다.

아치는 로고 외에도 히어로 일러스트(`NookArt.astro`), 이미지 프레임(`.arch-top`), 공간 아이콘(`.arch-icon`)으로만 쓰는 브랜드의 유일한 곡선입니다. 나머지 모서리는 모두 직각입니다.

## 색

| 토큰               | 값        | 용도                         | 대비                           |
| ------------------ | --------- | ---------------------------- | ------------------------------ |
| `--canvas`         | `#f6f3ee` | 페이지 배경 (린넨)           | —                              |
| `--surface`        | `#ece7df` | 패널·이미지 배경             | —                              |
| `--surface-strong` | `#e0d9ce` | 한 단계 진한 면              | muted 5.0:1                    |
| `--ink`            | `#1a1816` | 제목·본문                    | canvas 위 16.0:1               |
| `--muted`          | `#5e5850` | 보조 텍스트                  | canvas 위 6.4:1                |
| `--accent`         | `#3b5645` | 모스 그린 — 링크·활성·포커스 | canvas 위 7.3:1, 흰 글자 8.1:1 |
| `--night`          | `#1d201c` | 유일한 반전 밴드             | night-ink 14.9:1               |

색은 한 가지 포인트(모스)만 씁니다. 그라디언트는 히어로 일러스트의 음영 외에 쓰지 않습니다.

## 타이포그래피

- 본문·제목: **Pretendard Variable** (SIL OFL 1.1, 자체 호스팅). 제목은 SemiBold(600), 자간 −0.04em 안팎.
- 숫자·참조번호·가격: **IBM Plex Mono** 400.
- 한글은 단어 단위 줄바꿈(`keep-all`), 본문 행간 1.8, 제목 행간 1.14~1.34.
- 라틴 대문자 + 넓은 자간은 로고타입에만 씁니다. 한글 라벨은 대문자 장식 없이 Medium(500) 굵기로 위계를 만듭니다.

## 레이아웃과 모션

- 구획은 카드와 그림자 대신 **헤어라인**으로 나눕니다. 그림자, 둥근 모서리(아치 제외)는 쓰지 않습니다.
- 섹션 제목 위에 영문 캡션(eyebrow)을 달지 않습니다.
- 모션은 천천히 올라오는 등장, 이미지 열림, 선 그리기 정도로 제한하고, 모션 감소 설정과 JS 비활성 환경에서는 모든 요소가 최종 상태로 표시됩니다.

## 이미지

상품 사진이 준비되기 전까지는 사진 대신 아치 일러스트와 타이포그래피로 구성합니다. 사진이 생기면 다음 원칙을 따릅니다.

- 자연광, 차분한 배경, 한 장에 한 물건. 과한 연출 소품과 강한 색 보정은 피합니다.
- 상품 카드 비율 4:5, 갤러리 3장 기본. 대체 텍스트는 상품명과 보이는 내용을 설명합니다.
- 필요하면 `.arch-top`으로 아치형 프레임을 씌울 수 있습니다.
